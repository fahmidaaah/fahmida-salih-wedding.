FAHMIDA & SALIH — WEDDING INVITATION WEBSITE

HOW TO USE
1. Extract the ZIP file.
2. Open index.html in a browser, or upload the entire folder contents to GitHub Pages / Netlify.
3. Keep the images folder alongside index.html.

NAVIGATION
- Tap the visible Open / Swipe areas to move through the invitation.
- Swipe left/right on mobile, or use the left/right arrow keys on desktop.
- The venue button opens Google Maps.
- RSVP buttons show an on-screen acknowledgement (they do not send a response to the couple).

IMPORTANT
This version uses your supplied invitation images as the exact page artwork, so the text and design match the references. RSVP responses are not stored or sent anywhere yet.
